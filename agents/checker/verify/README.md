# Checker verify folder

Saved checks for the Checker. One script per equation, under `checks/`. A run
starts with `runs/<date>-<scope>/PLAN.md` and waits for approval before any new
script is added.

The Checker writes only in this folder. It does not edit the paper, the site,
or the other agents. `RESULTS.md` is generated by `verify_run.py`.
